# Results

## Benchmark results
Contains tables mapping the RMSE and MAE across the surrogate models.

## Comparison methodology
Models are evaluated strictly against the CFD FDM ground-truth datasets using reserved holdout sets (Test split).

## Evaluation metrics
Primary metrics:
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- Maximum Error (\infty$ norm)
